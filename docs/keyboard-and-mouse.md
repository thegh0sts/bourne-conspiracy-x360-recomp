# Keyboard and mouse controls

Turn on **Keyboard and mouse** in the launcher's Controls section. The layout is fixed: the
button prompts, the key images in the HUD and the quick-time-event prompts are drawn for it.

## On foot

| Key | Action |
|---|---|
| W / A / S / D | Move |
| Mouse | Look around (mouse look: the camera turns by as much as the mouse moves) |
| Left mouse | Fire |
| Right mouse | Aim; in cover with a gun, pop out |
| Shift | Sprint |
| Ctrl | Crouch |
| Space or Enter | Action: open doors, climb, vault, take cover, block |
| F or Backspace | Takedown; skip cutscenes |
| E or R | Reload |
| Q | Bourne Instinct (shows objectives and enemies) |
| G | Draw / holster the gun |
| Middle mouse | Recentre the camera; switch shoulder when aiming |
| Arrow keys | Turn the camera (like a controller's right stick) |
| 1 / 2 / 3 / 4 | D-pad up / down / left / right |
| Esc | Pause |
| Tab | Back |

## Fights

With **Fights: left / right mouse = light / heavy attack** on (the default):

| Key | Action |
|---|---|
| Left mouse | Light attack |
| Right mouse | Heavy attack |
| Space | Block |
| F | Takedown (when the adrenaline meter has a tier filled) |

With it off, E is the light attack and Q the heavy attack, as X and Y on a controller.

## Quick-time events

QTE prompts show the controller's four face buttons as a diamond. On a keyboard the diamond is
W / A / S / D in the same places:

| Prompt | Key |
|---|---|
| Top (Y) | W |
| Left (X) | A |
| Bottom (A) | S |
| Right (B) | D |

This works for every QTE, multi-takedowns and boss takedowns included. The usual keys for those
buttons (Space, F, E, Q) work too.

## Menus

| Key | Action |
|---|---|
| Enter or Space | Accept; on the title screen, start |
| Backspace or F | Back |
| W / S, or 1 / 2 | Move up and down |
| Esc | Pause / close |

## Keys the game keeps for itself

F3 debug overlay, F4 settings overlay, F7 achievements, \` console.
