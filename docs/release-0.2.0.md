**Performance, 60 FPS and image options.** You need your own copy of the game (Xbox 360 disc image); nothing from the game is included.

**Download `BourneConspiracy.exe`** and run it. The first time, it installs: pick your disc image and it builds the game on your PC (installs the C++ build tools if needed). After that, it's the launcher.

### Highlights
- **60 FPS** (experimental) and experimental 120 / 144 / unlimited, via the new **Frame rate** option.
- **Faster frame pacing:** the busiest scene went from about 48 to the mid-50s FPS at 1x, and the rest of the first level holds a solid 60.
- **Upscaling filter (FSR / CAS)** for a sharper picture at almost no cost (menu text gets softer, so it's off by default).
- **Turn off post-processing effects:** motion blur, depth of field, bloom, lens flares and heat haze each have their own switch.
- Working **render resolution**, **VSync**, **FPS counter**, **Open logs** and **Save crash report**.
- The installer now **bundles the ReXGlue SDK** (patched, with FidelityFX), so there's no SDK download.

### Caveats
- 60 FPS: the game was tuned for 30. If anything plays too fast or breaks, set Frame rate back to 30.
- Render resolutions above 720p are demanding (2x runs in the mid-teens in the busiest scene).

Tested on an Intel Core i7-12700KF, 32 GB RAM, NVIDIA GeForce RTX 4080 SUPER (driver 621.01), Windows 11.
