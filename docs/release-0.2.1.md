**Keyboard and mouse, and camera turn speed.** You need your own copy of the game (Xbox 360 disc image); nothing from the game is included.

**Download `BourneConspiracy.exe`** and run it. Already on 0.2.0? Run the new exe; it opens as the launcher and keeps your settings. Then click **Reinstall from a disc image...** on the settings screen so the game is rebuilt with the new code.

### Highlights
- **Keyboard and mouse** (experimental): tick **Keyboard and mouse** under Controls. W A S D, mouse camera, left mouse fire, right mouse aim; a controller still works alongside.
- **Editable key binds:** **Edit keys...** rebinds any action, two keys each, mouse buttons included.
- **Camera turn speed** (50-300%) for mouse and controller, and full-speed aiming with the mouse (the game's aiming slow zone is removed when keyboard and mouse is on).
- **Mouse sensitivity** now goes up to 1000%.

### Caveats
- The mouse drives a virtual controller stick, so it can still feel heavier than a PC game. Lower **Stick dead zone** (5-10%) and raise **Camera turn speed** first, then tune **Mouse sensitivity**. A low dead zone also applies to a controller; raise it if your pad drifts.
- Camera turn speed is new and still being verified in game.

Tested on an Intel Core i7-12700KF, 32 GB RAM, NVIDIA GeForce RTX 4080 SUPER (driver 621.01), Windows 11.
